#  Rekam Medis Elektronik (Back-End)

Backend sistem Rekam Medis Elektronik (RME) yang dibangun menggunakan Golang dengan menerapkan Clean Architecture. 
Sistem ini menyediakan REST API untuk mendukung pengelolaan data dan layanan rekam medis secara terstruktur.

## 🚀 Fitur
- CRUD data pasien
- Pencatatan rekam medis pasien
- Pengelolaan data pemeriksaan berdasarkan layanan/poli
- Penyimpanan riwayat pemeriksaan
- Penyediaan endpoint API untuk kebutuhan frontend
- Request dan response menggunakan format JSON
- MySQL sebagai database
- GORM sebagai ORM
- Clean Architecture
